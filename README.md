# Shamique Khan - AI/ML Portfolio

A modern, photography-inspired portfolio website showcasing AI/ML projects, certifications, and professional experience.

## 🎨 Design Features

- **Photography Portfolio Aesthetic**: Editorial-style layout with red (#8B1A1A), white, and cream (#F5F1E8) color scheme
- **Bebas Neue Typography**: Bold, distinctive titles with Inter for body text
- **Scroll Animations**: Comprehensive scroll-triggered animations using Intersection Observer
- **Multilingual Intro**: Animated "Hello" greeting in 10 languages
- **Responsive Design**: Fully responsive across all devices

## 🚀 Pages

- **Home** (`index.html`): Main landing page with about, photography, certificates preview
- **Projects** (`projects.html`): 20 AI/ML projects with filtering by category
- **Certificates** (`certificates.html`): 48 professional certifications with modal viewing

## 📂 Structure

```
Portfolio/
├── index.html              # Main landing page
├── projects.html           # Projects showcase
├── certificates.html       # Certificates collection
├── style-modern.css        # Main stylesheet
├── certificates/           # Certificate images
├── shamique khan photos/   # Portfolio photos
├── photography as hobby/   # Photography collection
├── photos/                 # Additional photos
└── vercel.json            # Vercel deployment config
```

## 🛠️ Technologies

- HTML5
- CSS3 (Custom animations, Grid, Flexbox)
- Vanilla JavaScript (Intersection Observer, Dynamic rendering)
- Google Fonts (Bebas Neue, Inter, Poppins)
- Font Awesome Icons

## 📱 Deployment

Ready for deployment on Vercel:

1. Push to GitHub repository
2. Import project to Vercel
3. Deploy automatically

No build process required - pure static HTML/CSS/JS.
