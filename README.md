# Shamique Khan — Portfolio

Personal portfolio built with React, Vite, TypeScript, Tailwind CSS, and Framer Motion.

**Aesthetic**: Editorial minimalist / Scandinavian. Warm monochrome. Typography-led hierarchy.

## Pages

| Route | Content |
|---|---|
| `/` | Hero + About snippet + selected work + experience timeline + Contact CTA |
| `/work` | 8 featured case studies + full 40-project GitHub inventory |
| `/research` | Four publications with publication and GitHub source links |
| `/certificates` | Credential backup, grouped by category |
| `/contact` | Direct contact page |

## Development

```bash
npm run dev     # Start dev server
npm run build   # Production build to dist/
npm run preview # Preview production build
```

## Deployment

Deployed on Vercel. SPA rewrites configured in `vercel.json`.
